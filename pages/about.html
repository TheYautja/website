About

I am a developer and computer science enthusiast interested in software development, computer systems and understanding the technical foundations of computing.

My work ranges from application development to lower-level programming. I enjoy exploring how software interacts with operating systems, hardware and other software components.

Technical interests

Field Topics
Programming languages C, C++, Dart, JavaScript and Rust.
Operating systems Linux, system interfaces, runtime environments and compatibility.
Software engineering Application architecture, debugging, development tools and testing.
Computer science Algorithms, data structures and computational theory.

Development philosophy

I prefer understanding the underlying mechanisms behind a system rather than relying exclusively on abstractions. This includes studying existing implementations, experimenting with unfamiliar technologies and building projects from the ground up.

Most of my development work is available through GitHub.
